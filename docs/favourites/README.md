# Избранное

Спецификация поведения и движения · версия 1 · 19 октября 2026.

Здесь описан **текущий работающий прототип**. Начните с этой страницы, затем откройте нужное взаимодействие. Для чтения не нужны Xcode и знание Swift. Время указано в миллисекундах от действия пользователя, размеры — в логических единицах интерфейса, а не в пикселях видеозаписи.

## Что делает раздел

На экране «Переводы и платежи» есть горизонтальная лента быстрых действий. В ней вместе живут рекомендации, частые операции и часть сохранённых избранных. Полный раздел «Избранное» содержит только операции, которые пользователь сохранил сам.

Из карточки можно перейти к предзаполненной оплате. Карандаш включает редактирование: карточки покачиваются, появляются крестики удаления. Удаление можно отменить в течение пяти секунд. Из истории можно создать новый шаблон и задать название и необязательную сумму.

**Сначала посмотрите:** [проморолик добавления из деталей операции](media/announcement.mp4). Это отдельная презентационная композиция; приближение камеры и уход соседних кнопок не являются поведением рабочего интерфейса.

| 09 | Сердце Pow Pop | Кольцо, частицы и заполненное сердце подтверждают сохранение | [Описание и пример](animations/09-heart-pop.md) |

**Анимация добавления в горизонтальную ленту удалена.** Новая подборка появляется без раздвигания, вспышки и автопрокрутки. Это относится и к замене карточки в заполненном слоте. Отдельный пример инпута тоже удалён, но плавное состояние поля суммы осталось в [настоящем редакторе](behaviour.md#редактор-избранного).

## Как устроена документация

- [Логика раздела](behaviour.md): подбор ленты, пустое состояние, оплата, создание и редактирование, эксперимент с папкой.
- [Перенос на другую платформу](implementation.md): общие состояния, единицы, пружины, карта исходников и границы прототипа.
- [Проверка реализации](verification.md): воспроизведение, проверенные случаи и команды.
- [Единый шаблон страницы анимации](../templates/motion-spec.md): для следующих спецификаций.
- [Почему выбран такой формат](sources.md): первичные источники Wise, Atlassian, Carbon, Spectrum и авторство эффектов.
- [Справочник параметров](motion-reference.json): точные значения из кода для проверки и автоматизации. Он не обязателен для первого чтения.

На каждой странице одинаковый порядок: **зачем → запуск → пример и этапы → параметры с объяснением → повторные действия → доступность → проверка → исходники**. Временные отметки раскадровки относятся к её ролику, а таблица этапов — к действию пользователя. Не используйте время паузы перед нажатием как задержку интерфейса.

## Что уже решено, а что остаётся экспериментом

| Состояние | Решение |
|---|---|
| Работает в полной версии | Девять взаимодействий выше; редактор; быстрая оплата; отмена удаления |
| Работает только в «Новом варианте» | Папка «Все избранные · N» с настоящими логотипами сохранённых операций |
| Сохранены как два варианта контекстного перехода | Move In и перелёт по заголовку; они пока не унифицированы |
| Не принято как продуктовое правило | Универсальное поведение для 7 / 8+ карточек; замена истории карточкой «Ещё N» |
| Не реализовано как продуктовый сервис | Серверное хранение, реальное ранжирование по банковским данным, расписание списаний, аналитика |

«Добавить из истории» сохраняется при любом количестве избранных. Анимация ничего не удаляет из бизнес-данных сама: она показывает уже выполненное действие.

## Посмотреть в приложении

В каталоге: **Избранное → Переводы и платежи / Новый вариант / Детали операции**. Отдельные анимации находятся в **Избранное → Анимации по отдельности**.

Быстрый запуск из корня репозитория на Mac с Xcode:

```sh
./scripts/preview.sh favourites/folder-test
./scripts/preview.sh favourites-animations/removal
```
