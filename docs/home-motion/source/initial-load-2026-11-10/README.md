# Снимок начальной загрузки · 10 ноября 2026

Источник: текущий `wb-test`, сборка `index-aZ1RUz81.js`. Это справочный снимок файлов, не отдельное запускаемое приложение: общие импорты и ассеты остаются в основном проекте.

[Спецификация](../../animations/03-initial-load.md) · [Запись](../../media/initial-load/initial-load.mp4)

`HomeIntro.tsx` задаёт ожидание и фазы. `PromoCards` в `main.tsx` завершает уменьшение → появление → наклон через `onAnimationComplete`. CSS содержит скелетоны и линейный шиммер. `CategorySlider.tsx` и `BannerCarousel.tsx` показывают включение автопереключения после `ready`. `home-intro.spec.ts` проверяет текущую последовательность реальными кадрами браузера.

Значения: 400 / 300 / 280 мс, cubic-bezier(0.22, 1, 0.36, 1). Снимок не заменяет архивные исходники общей суммы и карусели счетов в родительском каталоге.

## Граница применимости снимка

Это неизменённый технический пример веб-демо. Названия файлов, компонентов, состояний и обработчиков не задают имена в приложении разработчиков. Задержки и предел ожидания ресурсов в этом снимке — настройки демонстрации, а не требования. В актуальной спецификации скелетоны показываются произвольное время под управлением приложения; анимация начинается только по готовности контента. Уменьшение движения не меняет политику ожидания.
