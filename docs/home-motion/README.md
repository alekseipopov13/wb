# Главный экран · анимации и поведение

Спецификация поведения и движения · версия 8 · 11 ноября 2026.

Актуальная [анимация суммы](animations/01-balance.md) описана по **[wb-test-1](https://lyosha.fun/wb-test-1/)**: число, кегль, ширина и глазик меняются одновременно за 400 мс, центр суммы с ₽ неподвижен. Значения 52 000 ₽ и 489 943 312 433 ₽ — тестовые, не ограничения продукта.

Карточки и начальная загрузка сохраняют собственные спецификации. Основная [wb-test](https://lyosha.fun/wb-test/) продолжает показывать предыдущую анимацию суммы. Размеры — логические единицы интерфейса; шрифты учитывают системный масштаб.

## Начальная загрузка

[Начальная загрузка, кешбэк и приглашение друзей](animations/03-initial-load.md): скелетоны с шиммером → раскрытие контента → уменьшение кешбэка за 400 мс → появление приглашения за 300 мс → наклон за 280 мс. Добавлены запись, шкала времени и примеры для iOS и Android. Показ шиммеров длится столько, сколько задаёт приложение; отсчёт движения начинается по готовности контента. Названия элементов описательные, без привязки к компонентам разработчиков. Этот раздел не меняет параметры пересчёта.

## Что делает переключение

Выбор режима сразу меняет целевой баланс и доступные счета. Число плавно пересчитывается до нового значения. Кегль и межстрочный интервал меняются вместе с числом; центр суммы неподвижен, глазик плавно перемещается справа. Одновременно ненужные карточки опускаются за нижнюю границу маски, а нужные появляются снизу. Высота серой шапки остаётся постоянной.

## Что реализовано, а что является условием продукта

| Состояние | Решение |
|---|---|
| Начальная загрузка, версия 5 | Реализована в wb-test; актуальная запись и код — в разделе 03 |
| Архивный снимок | Смена режима, пересчёт, перемещение ₽ и глазика, маска карточек, скрытие баланса, горизонтальная прокрутка |
| Сумма, версия 5 | Реализована в wb-test-1: пересчёт и кегль одновременно, постоянный центр, глазик рядом; тесты на ширинах 320/390/430 и масштабе 100%/150% |
| Поддерживается компонентом | От одной до трёх WB-карточек; ширина зависит от количества |
| Данные демонстрации | Три WB-карточки и подключённый WB Кэш; фиксированные суммы |
| Условие продукта | WB Кэш должен показываться только если подключён; в текущем демо он отрисован всегда |
| Вне прототипа | Серверные балансы, загрузка и ошибки счетов, реальные банковские операции |

Промежуточное число — визуальный переход. Оно не является новым банковским балансом и не должно передаваться в расчёты, аналитику или озвучиваться на каждом кадре.

Видео, раскадровки и исходники разделов 01–02 фиксируют прежнюю версию. Для актуальной суммы используйте новые кадры раздела 01. Логика и параметры карточек этим обновлением не меняются.
