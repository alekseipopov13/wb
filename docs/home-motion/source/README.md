# Архив исходников · 22 октября 2026

Этот каталог сохраняет реализацию, на которой записаны старые видео и раскадровки. Он не обновляется при документационных правках и не является кодом новой логики.

В частности, `Math.round`, перемещение глазика, `minimumDigits={6}` и проверки старой геометрии относятся к архиву. Целевое поведение версии 4: [масштабирование суммы](../amount-scaling.md) и [смена суммы](../animations/01-balance.md).
