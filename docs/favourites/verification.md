## Запуск на Mac

Откройте `WBSandbox.xcodeproj` в Xcode и запустите схему `WBSandbox` на iPhone Simulator. В каталоге есть полные сценарии и девять отдельных примеров. Либо из корня репозитория:

```sh
./scripts/preview.sh favourites/payments
./scripts/preview.sh favourites/folder-test
./scripts/preview.sh favourites/operation-details
./scripts/preview.sh favourites-animations
./scripts/preview.sh favourites-animations/removal
```

`preview.sh` собирает и устанавливает приложение; нужен установленный Xcode с iOS Simulator. По умолчанию скрипт использует уже загруженный симулятор; при нескольких устройствах выберите одно перед запуском.

## Проверка без просмотра кода

| Случай | Ожидаемый результат |
|---|---|
| Новый клиент | Кошелёк и обезличенный телефон; сохранённых в полном разделе нет |
| Много операций | До шести карточек операций; история остаётся после них |
| Добавление из истории | Форма закрылась; сетка сдвинулась цепочкой; лента обновилась без вставки и автопрокрутки |
| Имя / сумма | Имя не пустое; «Без суммы» выключает поле, чип исходной суммы не теряется |
| Скролл напоминания | Уходит за край вместе с карточкой; не исчезает на месте и не вылетает повторно |
| Заголовок из начала | Move In справа |
| Заголовок у сохранённых | Полёт из текущих мест в измеренные слоты сетки |
| Лёгкий отскок у конца | Не открывает избранное |
| Протяжка 72, возврат ниже 54 | Готовность включается и отменяется; порог не дрожит |
| Удаление первой / средней / последней | Схлопывание и цепочка; при пустом списке остаётся история |
| Быстрая отмена | Продолжение из текущего кадра, без прыжка в конец удаления |
| Отмена после окончания движения | Возврат на прежнее место, без покачивания |
| Два удаления | Тост отменяет только последнее |
| После пяти секунд | Отмена не восстанавливает карточку |
| Сердце | Сохранение сразу; второй тап открывает редактор; эффект не меняет цвет токена |
| Reduce Motion | Функции доступны, большие перелёты и декоративное движение выключены |
| Фон приложения | Нет продолжающегося покачивания и частиц; возвращение не перезапускает старое подтверждение |

## Автоматические проверки

Из корня репозитория:

```sh
./scripts/check-favourites-handoff.sh
```

Скрипт проверяет правила ленты, сумму, отмену удаления, геометрию и порядок движения, пороги протяжки, закреплённую опору напоминания, ссылки документации и соответствие JSON настоящим таймлайнам. Он не проверяет сервер и не заменяет просмотр анимаций на устройстве.

Для сборки:

```sh
xcodebuild -project WBSandbox.xcodeproj -scheme WBSandbox \
  -configuration Debug -sdk iphonesimulator \
  -derivedDataPath .build CODE_SIGNING_ALLOWED=NO build
```

## Записи и раскадровки

На каждой странице есть GIF для быстрого просмотра, MP4 с нормальным темпом и четыре стоп-кадра. GIF с меньшей частотой кадров служит предпросмотром, не эталоном плавности. Тайминги реализации берутся из таблицы страницы и кода, а не из пауз записи перед нажатием.

Повтор GIF — удобство документации. Он не означает, что эффект автоматически
проигрывается по кругу в приложении.

Записи сделаны на демонстрационных данных. Проморолик `announcement.mp4` с камерой вынесен отдельно и не используется как запись поведения рабочего приложения.

Фактические результаты сборки и проверок для этой передачи: [validation.json](validation.json). Проверки на физическом устройстве, тактильный отклик, производительность целевого продуктового стека и интеграция с сервером в эти результаты не входят.
